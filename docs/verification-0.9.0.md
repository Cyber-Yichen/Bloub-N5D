# 0.9.0 验证记录

## 自动校验

- Vue / TypeScript 类型检查、Vite 生产构建及 Android 编译、打包、签名验证通过。
- 动画与交互测试共 237 项通过；最终灯环暗区宽度与随机故事筛选调整后，相关用例再次通过。
- 纯 Java 存储核心测试 120 项通过：以独立官方 SDK 输出对照 OSS / COS / S3 各三个签名样例，覆盖中文、空格、百分号路径和临时令牌；另外检查 Base64、JPEG XMP 解析与原像素保持、WebDAV 状态码。

## N5D 实机与网页

- 日期/时间范围导出：精确时间窗口只导出匹配照片，ZIP 中 JPEG、JSON、清单及 JPEG XMP 的拍摄时间与工位状态一致，导出 JPEG 可正常解码。
- 网页设置保存后同步到设备；图库、设置、监控在 390 px 网页宽度无横向溢出。设备五个设置页均无内容裁切。
- 原有两类真实校准样本保持不变。用仅作用于动画的临时诊断输入验证空位休息、在位唤醒、相机道具；未写入虚假工位标签或统计。
- 灯环入口 7 点、逆时针到 11 点，实际 RGB 暗区同时最多两颗；返回宽波推动角色并显示惊讶，剧情结束归还灯环。已恢复正常随机播放和原有开关设置。
- 实测静音 H.264 分段：960×1280、约 29.6 fps、15 秒配置产生约 14.8 秒视频，朝向信息正确，无音轨。停止网页预览不停止监控录像。
- WebDAV 模拟接收端先返回 503，确认保留待传视频；重试后收到 MP4 与 JSON，视频逐字节一致。设备 Keystore 凭证可解密用于上传，读取接口不返回密码。
- 连续 25 次监控重试 POST 均返回完整 JSON。测试结束已关闭监控和自动上传，删除模拟凭证及测试录像。
- APK 中包含 adaptive-icon 前景/背景与旧版兼容图标，安装保留已有应用数据。

## 尚未实测

真实 OSS / COS 存储桶、S3 服务及具体 NAS 固件的权限和连接行为需要实际环境验证。本版已验证协议签名与模拟端错误重试，不能据此声称所有服务配置均已通过。
