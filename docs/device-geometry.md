# N5D 整机坐标

来自用户提供的屏幕测量与正面尺寸估计。该坐标用于动画视觉连续性，不是 PCB 精密测量。

| 项目 | 值 |
| --- | --- |
| 屏幕 | 1600 × 720，约 150.7 × 67.8 mm |
| mm / 像素 | 0.0942 |
| 挖孔 | (44,360)，半径 24 ± 1 px |
| 显示圆角 | R60 px |
| 机身正面 | 242 × 74.5 mm |
| 灯环圆心 | (2150,360)，屏幕右侧 |
| 发光外径 / 内径 | 70.3 / 61 mm |
| 光带中线半径 | 32.8 mm，约 348.2 px |
| 彩灯 / 白灯 | 24 / 24，顶部起顺时针；白灯偏 7.5° |

灯位来源：[RingStudio light-layout](https://github.com/Cyber-Yichen/N5D-RingStudio/blob/main/docs/light-layout.md)。

彩灯 i 的角度为 iπ/12；白灯为 (i+0.5)π/12；位置为 (2150+r sinθ, 360−r cosθ)。场景轨迹和 LED 采样统一使用这套坐标。
