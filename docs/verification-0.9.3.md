# 0.9.3 验证记录

## 构建与核心逻辑

- WSL 构建通过 TypeScript 检查、Vite、原生 Java 编译和 D8；APK zipalign、v2/v3 签名验证通过。
- Java 核心测试 290 项通过，其中新增 36 项覆盖预览请求类型、编码参数、10/15/24/25/30 帧节奏、源时间戳、长时间断帧恢复、变化前后非对称窗口、零时长边界、裁切 / 旋转 / 镜像坐标和音轨文件尺寸估算。
- 最终 APK 已在设备安装，versionName 0.9.3 / versionCode 13。

## 真实录像

- 当前相机 2 可用 H.264；设备能力检查没有提供可用的 H.265 录像配置，网页仅显示 H.264，服务器拒绝 H.265 请求。
- 支持配置：1280×1080、1280×960、640×480；各支持 10/15/24/25/30 fps；码率范围 128–20000 kbps。
- 640×480 / 15 fps / 512 kbps + AAC：实际视频平均约 14.976 fps、508499 bps，AAC 约 63995 bps；文件约 1.02 MiB、14.98 秒。
- 1280×1080 / 24 fps / 1600 kbps，附加 90° 与镜像：实际像素 1080×1280，平均约 24.001 fps、1600302 bps；文件约 2.83 MiB、14.79 秒。解码帧上面部关键点、框和正常朝向的标签 / 时间戳位置已目视核对。
- 640×480 / 10 fps / 384 kbps 实际生成分段；完成后立即经签名上传 MP4 和 JSON。模拟 S3 服务独立计算真实请求签名并核对，整段启动、录制、上传在 23 秒内完成。队列中的待上传段继续处理。
- 测试后恢复原设置与已有录像的上传标记，删除本次测试片段和模拟凭证。

## 网页与预览

- 最终安装版本设备网页在 Chrome 验证，未出现 JavaScript 运行异常。
- 宽度 2560、1440、1280、768、390：监控无横向溢出，输入控件可用。拍摄间隔的有人 / 无人 / 未知标签、开关、数值在 1280 / 768 / 390 均完整显示。
- 录像画面保持展开，与实时监控预览相邻；编码、分辨率、帧率、码率及每段 / 每小时估算可见。
- 预览真实相机画面，90° 选项改变输出宽高；未保存草稿不改已保存的录像配置。
- 变化前单位切换保留实际秒数；网页提交变化前 20 秒 / 变化后 2 分钟，API 确认为 20 / 120 秒。还原配置通过。
- 每日定时模式显示时间选择，手动模式隐藏；每段录完模式的真实上传链路如上。
- 页面切换停止预览；实时观察与监控预览能同时运行。关闭监控预览仍保持实时观察与录像，关闭实时观察仍保持录像。
- 非法预览 options 类型或开关类型返回 400。
